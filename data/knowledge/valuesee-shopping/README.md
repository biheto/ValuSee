# ValuSee Shopping Knowledge Pack

适用范围：中国大陆常见线上消费场景。本文档是购物决策辅助资料，不替代法律意见、平台规则或商品页面的最新说明。

每条建议都应优先回到商品详情、订单页、商家承诺和官方规则核实。动态价格、促销、会员权益、价保期限、退换货流程和保修政策可能随平台、品类、地区、订单及时间变化。

## 文档

- `01-sku-identity.md`：如何核对商品是否同款、同版本、同配置。
- `02-total-cost.md`：如何计算可比的预计到手成本。
- `03-price-and-promotions.md`：如何核实促销、历史价和价保承诺。
- `04-returns-and-rights.md`：网购退货与消费权益核对清单。
- `05-seller-and-authenticity.md`：商家身份、交易凭证和正品风险核对。
- `06-review-evidence.md`：怎样使用评论作为有限证据。
- `07-warranty-and-after-sales.md`：保修、退换、维修及耗材的购买前核对。
- `08-fit-and-safety.md`：预算、使用场景、兼容性与安全适配。
- `sources.md`：官方来源及检索说明。

## 维护

从 ValuSee 项目根目录运行 `python -m scripts.seed_shopping_knowledge` 可将 Markdown 文档幂等写入 `valuesee-shopping` collection。更新政策性内容前应重新核对来源和生效日期。
